Entenda as Classificações de Performance

O dashboard classifica automaticamente os tempos de resposta da sua API em seis níveis de performance para ajudar a identificar gargalos:

Excelente ≤ 100ms. Tempo de resposta ótimo.
Bom ≤ 300ms. Tempo de resposta aceitável.
Aceitável ≤ 500ms. Dentro da média, potencial de melhoria.
Atenção ≤ 750ms. Resposta lenta detectada.
Ruim ≤ 1000ms. Alta latência detectada.
Crítico > 1000ms. Gargalo crítico de performance.
